# Frontend em React com TypeScript e Vite, não Angular

O enunciado aceita React ou Angular. Escolhemos React com Vite: para uma página só (abas de Pedidos e Top Clientes, mais o modal de criação), sem router, é mais leve, o build é rápido, o container fica pequeno e o deploy estático na Vercel é direto. O ecossistema também cobre bem a validação de dados na borda com schema.
