# Backend em .NET 10, não .NET 8

O enunciado pede ".NET 8 ou superior". Escolhemos o .NET 10 (LTS) porque o suporte do .NET 8 terminou em 10/11/2026, antes da entrega. Entregar sobre um runtime sem patches de segurança contradiz o requisito OWASP (A06, componentes vulneráveis e desatualizados). Não volte para o .NET 8 por "compatibilidade com o enunciado": ele é atendido pelo "ou superior".
